# 블록 키트 — 손바느질 부품

스마트에디터 ONE은 raw HTML이 안 된다.  
아래는 **에디터에서 손으로 재현**할 부품 설명 + 텍스트 시드.

| 파일 | 부품 |
|------|------|
| `01-mast.txt` | 상단 배지 스트립 |
| `02-oneline.txt` | 한 줄 요약 패치 |
| `03-demo.txt` | 시범(YouTube) |
| `04-follow.txt` | 따라하기 3단 |
| `05-drill.txt` | 실전 체크 |
| `06-judgment.txt` | 판단 인용 |
| `07-links.txt` | 링크 패치 |
| `08-foot.txt` | 푸터 스티치 |

주간 서식 = 위 순서대로 한 번 조립 → 서식 저장.
