## 0. 솔직한 반성 (커뮤니티 리서치 범위)

| 처음에 한 것 | 부족했던 것 |

## 1. 용어 정리 (헷갈리면 여기)

| 말 | 네이버 실제 기능 | 우리 패키지 |
|----|------------------|-------------|
| **템플릿** | 글쓰기 안 메뉴: 추천 / 부분 / **내 템플릿** | 매주 쓰는 **퀼트 패턴** |
| **서식** | 글자 굵기·색·인용구 등 (속성 막대) | 템플릿 만들 때 손질하는 것 |
| **스킨** | 블로그 전체 껍데기 HTML/CSS | `skin-custom.css` 1회 |
| **HTML 붙여넣기** | SE ONE에서 **사실상 불가** | `naver_template.html` = 레거시 참고만 |

**커뮤니티 정석 = 「내 템플릿」에 글 한 편 통째로 저장 → 매주 불러와 글자만 교체.**

## 2. 솔루션 A — 내 템플릿 1회 등록 (PC 권장)

### A-1. 재료 준비

1. 미리보기 눈으로 구조 익히기  
   `naver/quilt/weekly-seosik-preview.html`  
   또는 https://helena751107.github.io/helena_phone/naver/quilt/weekly-seosik-preview.html
2. 텍스트 골격 열기  
   `naver/quilt/weekly-seosik-paste.txt`  
   (또는 채운 예: `sample-week-filled.txt`)

### A-2. 등록 클릭 경로 (커뮤니티+공식 합본)

```
PC 네이버 로그인
  → 블로그 → [글쓰기]
  → (선택) 오른쪽/상단 [템플릿] 열어 구조 참고만 — 추천 템플릿은
      적용 시 기존 글 날아감 → 비우거나 임시저장 후
  → 본문에 weekly-seosik-paste.txt 내용 붙여넣기
  → 에디터로 손질:
        · 제목 줄 / 소제목 / 인용구 / 구분선 / 체크 목록
        · 【슬롯】 자리는 그대로 두거나 "여기 바꿔" 표시
  → [템플릿] → [내 템플릿] → [+ 현재 글 추가]  (또는 "현재글 추가하기")
  → 이름: Marine Quilt 주간
  → 저장
  → 이 글은 발행 안 해도 됨 (임시저장 후 닫아도 템플릿은 남음)
```

**앱에서 등록:** 가능하나 PC가 편함.  
앱 불러오기: `글쓰기 → ⋯(더보기) → 템플릿 → 내 템플릿`.

### A-3. 등록 시 커뮤니티 주의 (빨간 줄)

| 하지 마 | 이유 |
|---------|------|
| 지도·스마트플레이스 박제 | 무관한 글에도 장소 반복 노출 (redwave102 팁) |
| 추천 템플릿 중간에 덮어쓰기 | **기존 본문 삭제**됨 → 임시저장 먼저 |
| HTML 소스 기대 | ONE에 raw HTML 모드 없음 |
| 이미지 대량 박제 | 템플릿 무거움 · 매주 YT URL만 |

## 3. 솔루션 B — 매주 사용 (퀼트 손바느질)

```
① TG에 주간 패키지 도착 (tg-package-template.md 형식)
② 글쓰기 → [템플릿] → [내 템플릿] → 「Marine Quilt 주간」 선택
③ 【 】 슬롯만 TG 내용으로 교체   ← 한 땀
④ YouTube URL 한 줄 붙여넣기 → 카드 확인
⑤ (선택) 이미지 삽입
⑥ 카테고리·태그·발행
```

소요: 연습 후 **5~10분**.  
자동화 대상 아님 = 브랜드(수공예 퀼트).

## 4. 솔루션 C — 부분 템플릿 (선택, 고급)

커뮤니티에서 많이 씀: **글 전체가 아니라 부품만.**

| 부분 템플릿 이름 예 | 내용 |
|--------------------|------|
| MQ-한줄 | 인용구 + 한 줄 슬롯 |
| MQ-시범 | ① 시범 제목 + YT 자리 |
| MQ-따라 | 1·2·3 단계 번호 |
| MQ-실전 | ☐ ☐ ☐ |
| MQ-푸터 | 링크 패치 + 스티치 푸터 |

등록법: 부품만 본문에 놓고 → 내 템플릿(또는 부분으로 쓰는 습관) 저장.  
우리 `blocks/01~08` 텍스트가 부품 원단.

**초심자:** 전체 1개(Marine Quilt 주간)만.  
**숙련:** 부분 템플릿으로 조립 속도↑.

## 5. 솔루션 D — 스킨 (템플릿과 별개, 1회)

```
관리 → 스킨/디자인 → HTML·CSS 편집
→ skin-custom.css 맨 아래 붙여넣기 → 저장
```

스킨 = 블로그 **전체 톤**.  
템플릿 = **글 한 편 골격**.  
둘 다 해야 퀼트가 완성. 스킨만 해도 본문 톤, 템플릿만 해도 구조.

## 6. 솔루션 E — 쓰지 말 것 (리서치 결론)

| 유혹 | 판정 |
|------|------|
