## 에이전트 작성 규칙 (조교×퀼트)

| 규칙 | 내용 |
|------|------|
| 제목 | 명사 나열 금지. **동사로 끝** (예: “easy 한 줄로 끝낸다”) |
| 한 줄 | 20~40자. 마케팅 수사 금지 |
| 시범 | 영상 1개만. “나중에 더” 금지 |
| 따라하기 | **3단계 고정**. 4단계 이상이면 다음 주로 |
| 실전 | 체크 가능 문장만 (☐ 로 시작) |
| 판단 | YouTube 조교 톤 1줄 + 퀼트 장인 이유 2~3문장 |
| 금지 | 토큰 강제, OWNER 설명 장황, HTML, “자동화 완료” 표현 |

## Boss 손바느질 순서 (5~10분)

1. 네이버 글쓰기 → **서식: Marine Quilt 주간** 불러오기  
2. TG에서 제목·한 줄·단계·체크·판단 복사 → 슬롯 교체  
3. YouTube URL 붙여넣기 (카드 확인)  
4. 이미지 있으면 삽입  
5. 미리보기 → 발행  
6. TG에 “퀼트 완성 ✅ + 글 URL” 짧게 회신 (선택)
