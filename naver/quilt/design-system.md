# Marine Quilt — 네이버 디자인 시스템

> 확정 톤: **YouTube = 해병대 조교** · **Naver = 수공예 퀼트 장인**  
> 조사 기준일: 2026-07-27 · agent _Grok

---

## 1. 커뮤니티·플랫폼 쓰레기통 리서치 요약

| 출처 유형 | 쓸 것 | 버릴 것 |
|-----------|--------|---------|
| 홈페이지형 스킨 (투명 위젯·이미지맵) | “여백·블록 리듬” 감각 | 5개 투명위젯 조립 지옥 (초심자·주간 운영에 부적합) |
| 유료 스킨 스토어 | 타이포 여백·1단 집중 | 장식 과다, 광고 위젯 밀집 |
| 스마트에디터 ONE 제약 | **서식 저장·YouTube URL 카드·이미지 삽입** | raw HTML 모드 (없음) |
| 기존 helena Paste Pipeline | TG 배달 → 손 붙여넣기 | GUI 자동화·매크로 |
| 기존 `naver_template.html` | 섹션 골격 | HTML 붙여넣기 전제 (폐기 경로) |

**결론:** 스킨은 **1회 CSS + 최소 위젯**. 글은 **서식(패턴) + 한 땀 붙여넣기**. 자동 발행 아님 = 퀼트 손맛.

## 2. 브랜드 이중성 (절대 섞어 깨지 말 것)

| | YouTube (조교) | Naver (퀼트 장인) |
|--|----------------|-------------------|
| 말투 | 각 잡고 들어와 · 장비 탓 마라 | 한 땀 한 땀 정성 |
| 리듬 | 시범 → 따라하기 → 실전 | 템플릿 + TG 배달 + 손조립 |
| 시각 | 군기·대비·짧은 컷 | 린넨·스티치·패치 블록 |
| 금지 | 변명·옵션 폭주 | 자동화 티 내는 UI, 차가운 SaaS 톤 |

Naver 화면에서 조교 고함만 치면 이탈한다.  
**구조는 해병대(엄격한 순서), 표면은 퀼트(따뜻한 손맛).**

## 3. 토큰 (Design Tokens)

```
--mq-deep:        #0F1C18   /* 해병 밤 — 헤더/배지 배경 */
--mq-olive:       #2C4035   /* 군복 올리브 */
--mq-crimson:     #9B1B1B   /* 해병 배지 빨강 */
--mq-khaki:       #C4A574   /* 실·카키 포인트 */
--mq-thread:      #D4A84B   /* 금실 (강조 링크) */
--mq-cream:       #F6F1E7   /* 린넨 종이 본문 배경 느낌 */
--mq-patch:       #EDE6D9   /* 패치 블록 */
--mq-patch-mint:  #DCE5DC   /* 성공/완료 패치 */
--mq-stitch:      #8B7355   /* 바느질 점선 */
--mq-ink:         #1C1917   /* 본문 */
--mq-mute:        #6B6560   /* 보조 글 */
--mq-rule:        rgba(15,28,24,0.12)
```

### 타이포

| 역할 | 규칙 |
|------|------|
| 배지 / 라벨 | 작은 대문자 느낌, letter-spacing 0.12em, 해병 딥 |
| 제목 | 굵게, 1.35 줄간격, 과장 이모지 남발 금지 |
| 본문 | 1.85 줄간격, 문단 사이 여백 넉넉 |
| 코드/로그 | 모노, 크림 패치 안 |

### 스티치 문법

- 섹션 구분 = **점선 1px** (`border: 1px dashed var(--mq-stitch)`)
- 중요 한 줄 = **왼쪽 4px solid crimson** 패치
- 완료 = mint 패치 · 대기 = khaki 얇은 테두리

## 4. 주간 퀼트 레이아웃 (서식 골격)

```
① MAST — 배지 스트립 (WEEK · VOL · MARINE QUILT)
② TITLE — 제목 1줄 + 날짜
③ ONE-LINE — 이번 주 한 줄 (크림 패치)
④ DEMO — 시범 (YouTube URL → 카드)
⑤ FOLLOW — 따라하기 (번호 3~5단계)
⑥ DRILL — 실전 체크 (☐ 목록)
⑦ JUDGMENT — 이번 주 판단 (인용)
⑧ LINKS — 패치 링크 (Pages · GitHub · YT)
⑨ FOOT — 스티치 푸터
```

**시범 → 따라하기 → 실전** = 조교 교범.  
**패치 블록 손조립** = 퀼트 장인.

## 6. 성공 기준

1. 스킨 적용 후 본문이 **크림·스티치 리듬**으로 읽힌다.  
2. 서식 불러오기 → TG 내용 슬롯만 교체 → 5~10분 발행.  
3. YouTube 링크는 네이버가 카드로 말아 준다 (손맛 유지).  
4. HTML 모드·매크로·봇 없음.
