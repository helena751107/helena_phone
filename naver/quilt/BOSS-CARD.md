# Boss 카드 — Marine Quilt 3분 설치

> 자동화 아님. **스킨 1회 + 서식 1회** 후, 매주 손바느질.

---

## A. 스킨 (1회)

1. 네이버 블로그 **관리** → 스킨 / 디자인 → **HTML·CSS 편집**
2. PC에서 파일 열기:  
   `naver/quilt/skin-custom.css`  
   (또는 Pages: 배포 후 raw 경로)
3. CSS 칸 **맨 아래**에 전체 붙여넣기 → 저장·적용
4. 글 하나 열어 본문 톤(크림·점선·링크 색) 확인  
   깨지면 방금 붙인 블록만 삭제 = 원복

선택: `skin-widgets.html` 안의 소개 문구를 프로필/공지에 옮기기.

---

## B. 내 템플릿 (1회) — 네이버 실사용 경로

> 자세한 클릭 순서·커뮤니티 주의:  
> **`naver/quilt/HOW-TO-USE-NAVER-TEMPLATE.md`**

1. 미리보기: `weekly-seosik-preview.html`
2. `weekly-seosik-paste.txt` 복사
3. 네이버 PC **글쓰기** → 본문 붙여넣기 → 인용구·구분선·목록 손질
4. **[템플릿] → [내 템플릿] → [+ 현재 글 추가]**  
   이름: `Marine Quilt 주간`
5. 테스트: 새 글 → 같은 템플릿 불러오기 1회

---

## C. 매주 퀼트 (5~10분)

```
① TG에 주간 패키지 도착
② 글쓰기 → 서식 「Marine Quilt 주간」 불러오기
③ 【 】 슬롯만 TG 내용으로 교체   ← 손바느질
④ YouTube URL 붙여넣기 (카드 확인)
⑤ 이미지 있으면 삽입
⑥ 발행 → 한 주의 퀼트 완성
```
