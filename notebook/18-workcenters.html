항목 값
역할 코드 + 문서의 SSOT (Single Source of Truth)
투입 STT 음성 → Claude Code → git commit
산출 코드·문서·설정·devlog·헌법
소유 helena751107 (큰누나 명의)
협업자 dtslib1979 (admin)
공개 전체 공개 (Public)
알림 push → TG 보고
