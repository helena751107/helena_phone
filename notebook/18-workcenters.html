## 콘텐츠 흐름도 (1개 콘텐츠의 생애)

```
1. 음성으로 아이디어 설명 (STT)
         │
2. Claude Code가 스크립트/원고 초안 작성
         │
3. GitHub에 원고 커밋 (공장)
         │
    ┌────┴────┐
    │         │
4a. 영상녹화     4b. 마크다운 변환
    │              │
5a. yt_upload.py  5b. publish.py
    │              │
6a. @helena_phone 6b. galaxys21-pwuser.tistory.com
    │              │
    └────┬─────────┘
         │
7. 네이버 관제탑에 "이번 주 픽" 등재
         │
8. tg.sh → 텔레그램 보고
   dc.sh → 디스코드 #ai-보고 (예정)
```
