# 📋 Paste Pipeline — "사람+기계 협업 발행" 방법론

> 발견: 2026-07-25 | Boss + Claude Code 협업
> 이 방법은 API가 막힌 플랫폼에서도 자동화의 이점을 살리는 합법적 최적화 전략이다.

---

## 1. 문제

네이버·티스토리 등 한국 블로그 플랫폼은:
- API가 없거나 (네이버)
- API가 폐기되었거나 (티스토리, 2024년 2월)
- HTML 모드가 제거됨 (스마트에디터 ONE)
- GUI 자동화를 적극 차단 (안티봇·CAPTCHA·레이아웃 변경)

개발자는 여기에 에너지를 쏟다가 번아웃된다.

## 2. 해결: Paste Pipeline

```
Claude Code → 텔레그램 전문 배달 → 사람이 복사 → 블로그 붙여넣기 → 발행
                   │
     YouTube + GitHub Pages = 무료 영구 CDN
```

### 원리

1. AI가 **전문 원고를 작성**한다 (제목·본문·링크·영상/이미지 제안 포함)
2. AI가 **CDN 자산을 준비**한다 (YouTube 영상 업로드, GitHub Pages에 이미지·문서 호스팅)
3. AI가 **텔레그램으로 패키지를 배달**한다 (플랫폼의 문자 제한 내에서 최대 분량)
4. 사람이 **복사→붙여넣기→편집→발행**한다 (5분)

## 3. 왜 막을 수 없는가

| 방어 레이어 | Paste Pipeline의 대응 |
|------------|---------------------|
| API 차단 | API를 전혀 사용하지 않음. 텔레그램은 정식 Bot API 사용 (정책 위반 아님) |
| HTML 모드 제거 | HTML이 아닌 순수 텍스트 전달. 에디터가 거부할 수 없음 |
| 안티봇 | 사람이 직접 복사·붙여넣기·발행 — 모든 행동이 인간 패턴 |
| 매크로 감지 | 주 1회, 사람의 마우스/터치 조작 — 매크로 패턴과 완전히 다름 |
| IP 차단 | 정상적인 사용자 트래픽 |

## 4. CDN 인프라 (무료·영구)

| 자산 유형 | CDN | 비용 |
|----------|-----|------|
| 이미지·문서 | GitHub Pages (`helena751107.github.io/helena_phone/img/`) | $0 |
| 영상·클립 | YouTube (`@helena_phone`) | $0 |
| 코드·데이터 | GitHub Raw (`raw.githubusercontent.com/...`) | $0 |

## 5. 텔레그램 패키지 형식

```
[제목]

[본문 — 볼드·줄바꿈·구분선으로 구조화]

[📺 영상 제안: 설명 + 예상 분량 + 목적]
[🖼️ 이미지 제안: 설명 + 추천 소스 URL]

[🔗 링크 — 전체 URL]
```

## 6. 플랫폼 호환성

| 플랫폼 | Paste Pipeline | 비고 |
|--------|---------------|------|
| 네이버 블로그 | ✅ | YouTube URL → 자동 미리보기 카드 |
| 티스토리 | ✅ | 동일 |
| 브런치 | ✅ | 동일 |
| Medium | ✅ | URL 자동 임베드 |
| 네이버 카페 | ✅ | 텍스트+링크 |
| 인스타그램 | ⚠️ | 링크 안 됨. 이미지+영상은 직접 |

## 7. 핵심 인사이트

> **"자동화할 수 없는 것을 자동화하려고 기를 쓰는 대신,**
> **사람과 기계의 협업 지점을 정확히 찾아 최적화하라."**
>
> AI의 강점은 원고 생성·자산 준비·포맷팅이다.
> 사람의 강점은 복사·붙여넣기·미적 판단·발행 버튼 클릭이다.
>
> 둘을 분리하면, API가 없어도 파이프라인은 돈다.
