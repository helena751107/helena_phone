# 🔄 Claude-Grok 협업 파이프라인

> 발견: 2026-07-25 | Boss 제안
> 텍스트는 Claude Code, 시각은 Grok. 사람이 연결고리.

---

## 1. 파이프라인

```
Claude Code                   사람                      Grok
──────────                   ────                      ────

① 텍스트 대본 작성
   (제목·본문·링크·
    이미지 위치 주석)
        │
        ▼
② TG로 대본 배달 ───→ ③ 복사·붙여넣기
                       네이버 발행
                           │
                           ▼
                      ④ 발행된 글 링크 ───→ ⑤ 네이버 글 파싱
                                              본문 이해
                                                  │
                                                  ▼
                                              ⑥ 이미지 생성
                                                 (삽화·표지·
                                                  다이어그램)
                                                  │
                                                  ▼
                                              ⑦ 짧은 클립 생성
                                                 (요약·하이라이트)
                                                  │
                                                  ▼
                      ⑧ 이미지·클립 수령 ←─── 생성물 전달
                      네이버 글에 추가
                      (또는 다음 주에 활용)
```

## 3. Grok에 보내는 프롬프트 예시

```
이 네이버 블로그 글을 읽고:
https://m.blog.naver.com/helena1975/224357424597

다음을 생성해줘:

1. 표지 이미지 (1080x720)
   - 제목: "갤럭시 S21, AI 워크스테이션이 되다"
   - 다크 테마, 터미널 창과 폰이 보이는 구도

2. 본문 삽화 3장
   - 트랙1 돌봄: 따뜻한 느낌, 보호·안전 상징
   - 트랙2 소망: 밝은 느낌, 목소리·글쓰기 상징
   - 워크센터 7종: 다이어그램 스타일

3. 30초 요약 클립
   - 글의 핵심을 전달하는 숏폼 영상
   - 자막 포함
```

## 4. 현재 Claude Code WebFetch와의 차이

| | Claude Code | Grok |
|---|------------|------|
| 네이버 파싱 (WebFetch) | ❌ | ✅ |
| 네이버 파싱 (proot curl) | ✅ | ✅ |
| 텍스트 생성 | ✅ (한글 최적화) | ⚠️ |
| 이미지 생성 | ❌ | ✅ |
| 영상 생성 | ❌ | ✅ |
| 코드·터미널·자동화 | ✅ | ❌ |

**결론: 둘 다 필요하다.** Claude Code는 텍스트+코드, Grok은 시각+네이버.

---

## 5. 비용 정당화

| 항목 | 월 비용 |
|------|--------|
| Grok (X Premium) | 45,000원 |
| Claude Code (DeepSeek) | $0 |
| **합계** | **45,000원** |

**45,000원으로 얻는 것:**
- 웹진 매주 3~5장 고품질 삽화
- 글 요약 숏클립 (YouTube Shorts 대체 가능)
- 네이버 글 파싱·피드백 (다음 주 주제 발굴)

**안 쓰면:** 이미지 없는 텍스트-only 웹진, YouTube Shorts 직접 촬영.

---

## 6. 적용 타이밍

| 시기 | 액션 |
|------|------|
| **지금** | Claude Code로 텍스트 대본만 생산. 이미지는 YouTube 클립으로 대체. |
| **2~3주 후** | 웹진 2~3회 발행 성공 → Grok 도입 검토 |
| **도입 시** | 위 파이프라인 가동. Claude Code가 Grok용 프롬프트도 자동 생성 |

---

> **핵심:** Claude Code는 못 하는 게 있고, Grok은 못 하는 게 다르다.
> 둘을 붙이면 하나의 완전한 콘텐츠 공장이 된다.
> 사람은 그 가운데서 방향만 잡아주면 된다.
