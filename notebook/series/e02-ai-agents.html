협업 파이프

1
Boss 방향 제시
"이거 만들어" — 짧은 프롬프트. 상세 명세 불필요.
2
Claude Code 설계 (DeepSeek)
콘텐츠·구조 설계. 마크다운 초안. 80% 완성도 → Boss 확인. Grok 있으면 비주얼 보강.
3
Aider + Claude Code 시공
$ python3 perfect_ship.py --url helena_phone --out e01.mp4
CLI 파이프 실행. Git 커밋·푸시. TG 보고. Playwright+ffmpeg+edge-tts 전부 무료 도구.
4
Boss SHIP 결정
품질 확인·TG 수령·최종 판단. "됐다" 또는 "다시". 사람만이 내릴 수 있는 결정.
현실: Grok 없이도 DeepSeek(Claude Code+Aider)+edge-tts+ffmpeg+Playwright로 24편 시리즈 전체를 제작 중이다. Grok은 비전 검수·고급 디자인이 필요할 때만 켜는 옵션.
