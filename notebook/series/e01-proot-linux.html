설치 4단계

처음부터 끝까지, 터미널 명령어 5줄. 각 단계를 클릭하면 상세 명령어가 표시됩니다.

1
F-Droid에서 Termux 설치
$ f-droid.org → Termux → 설치
# 또는 직접 APK 다운로드
2
Termux:API + 기본 패키지
$ pkg install termux-api nodejs python git
# Android 센서 · 카메라 · 알림 접근 권한
3
proot Ubuntu 설치
$ bash g/install.sh
# Ubuntu 24.04 ARM64 · Python3 · FFmpeg · Playwright
# 10분 소요. 재부팅해도 유지.
4
AI 에이전트 연결
$ claude
# DeepSeek API → Claude Code 세션 시작
$ grok "안녕"
# Grok CLI · xAI SuperGrok 구독
