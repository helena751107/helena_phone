워크센터 7종

① GitHub (공장) — Claude Code

항목 값
누가 Claude Code
하는 일 코드 작성·문서화·커밋·push
투입 STT 음성 명령
산출 커밋·문서·설정파일
빈도 실시간
상태 🟢 가동 중 (39커밋)

② GitHub Pages (전시장) — 자동

항목 값
누가 Git push → 자동 배포
하는 일 정적 웹사이트 호스팅
투입 GitHub repo의 index.html
산출 5개 .github.io 사이트
빈도 push 마다 자동
상태 🟢 라이브

③ YouTube @helena_phone (방송탑) — Claude Code

항목 값
누가 Claude Code (scripts/yt_upload.py)
하는 일 영상 업로드·메타데이터·플레이리스트
투입 사람이 녹화한 영상 파일 + Claude가 작성한 제목/설명
산출 YouTube 영상
빈도 영상 찍을 때마다
상태 🟢 OAuth 완료, 업로더 준비 완료

④ Telegram (내부 보고) — Claude Code

항목 값
누가 Claude Code (tg.sh)
하는 일 작업 완료·에러·건강·돌봄 알림
투입 Git push, 건강검진, 데몬 이벤트
산출 @S21Phone_Bot 메시지
빈도 이벤트 발생 시
상태 🟢 가동 중

⑤ 티스토리 galaxys21-pwuser (업무일지) — 사람

항목 값
누가 헬레나 (사람)
하는 일 작업일지·터미널 스크린샷·TG 리포트 요약 발행
투입 Claude Code가 생성한 TG 리포트 + git log + 폰 스크린샷
산출 티스토리 블로그 포스트
빈도 매일 또는 주 3회
상태 🟡 사람 손 (API 없음 — 자동화 포기)

⑥ 네이버 helena1975 (관제탑) — 사람

항목 값
누가 헬레나 (사람)
하는 일 주간 대표 콘텐츠 모아서 이미지+링크 발행
투입 GitHub·YouTube·티스토리 주간 산출물
산출 네이버 블로그 포스트
빈도 주 1회
상태 🟡 사람 손 (API 없음 — 자동화 포기)

상태 🟢 라이브 (dc.sh 알림은 예정)

한눈에

# 워크센터 주체 자동/수동 비유
① GitHub Claude Code 🤖 자동 공장
② GitHub Pages Git hook 🤖 자동 전시장
③ YouTube Claude Code 🤖 자동 방송탑
④ Telegram Claude Code 🤖 자동 내부 인터컴
⑤ 티스토리 헬레나 ✋ 수동 업무일지
⑥ 네이버 헬레나 ✋ 수동 관제탑
⑦ Discord 혼합 🔄 혼합 외부 로비

하나의 작업이 흐르는 길

1. 헬레나가 STT로 Claude Code에 지시
        │
2. Claude Code가 코드/문서 작성 → git commit → GitHub ①
        │
3. git push → GitHub Pages 자동 배포 ②
        │
4. Claude Code가 tg.sh → Telegram 보고 ④
        │                              │
5. (영상 필요 시)                      │
   사람이 폰 화면 녹화                  │
   Claude Code가 yt_upload.py → YouTube ③
        │                              │
        └──────────────┬───────────────┘
                       │
6. Telegram 리포트 + git log + 스크린샷
   → 사람이 티스토리 업무일지 발행 ⑤
        │
7. 주간 요약 → 사람이 네이버 관제탑 발행 ⑥
        │
8. 모든 산출물 → Discord 위젯으로 유입 ⑦

원칙: 열린 문으로 들어가라. 닫힌 문은 두드리지 마라.
API가 있는 건 Claude Code가, 손맛이 필요한 건 사람이.
이게 자원 배분이지 포기가 아니다.
