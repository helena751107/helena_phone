수동 작업 (폰 브라우저)

1. console.cloud.google.com → 새 프로젝트 "S21 YouTube"
2. OAuth 동의 화면 → 외부 → 앱이름 "S21 Phone" → 테스트 사용자 추가
3. 사용자 인증 정보 → OAuth 클라이언트 ID → "TV 및 제한된 입력 장치"
4. 클라이언트 ID + 시크릿 복사
