채널 정체성 확정: 돌봄(케어) 하이테크 IT 인프라 채널 — 가족사(헬레나 스토리)를 미러링해서
비슷한 사람들이 “돌봄 데몬”을 어떻게 만들 수 있는지를 보여주는 프로그래밍/인프라 채널.

1. 채널 정체성 (한 줄)

“스토리를 어떻게 기술적으로 케어할 수 있는가” — 거의 프로그래밍 영역.
누나의 가족사를 미러링 → 같은 처지의 사람들이 어떤 솔루션(돌봄 데몬)을 만들지 보여주는
인프라·하이테크 IT 채널.

  • 여기는 기술 노트도, 순수 스토리도 아니다. 둘의 교집합이다.
  • 돌봄 이야기가 정적/맥락적이듯, 돌봄 데몬은 소유가 아니라 신원관리다 ([[ai-era-speed-vs-judgment]]·[[voice-strategy-three-track]]의 “목소리 코어≠폰트”와 같은 논리).

3. 콘텐츠 처분 — 3버킷

  1. 삭제 (7편 빵꾸) — 콘텐츠 없음. 티스토리 글 삭제 API 또는 관리자 UI로 제거.
  2. S21 이동 (4편 IT/기술) — 텔레그램 봇/회의실, 지식공장, 티스토리 플랫폼, 박씨캡쳐.
    이들은 “돌봄”이 아니라 소망/기술 인프라 → galaxys21(테크 채널) 또는 helena_phone 원고로 이동.
    - 원고는 reverse_fetch/mynote/00xx__*.html에 이미 저장됨 → S21 원고로 재편.
  3. 유입 (돌봄 데몬 콘텐츠) — 아래 매핑.

티스토리 웹페이지 코드 (apply_skin.py · switch_skin.py · skin-premium.css · apply_layout.py ·
director_gate.py · history_batch.py 등) → 이미 helena_phone/tistory-naver/ 에 보관됨.
별도 이동 불필요. 커밋 정리만 (아래 5단계).

4. 카테고리 매핑 — 원천 → 카테고리

카테고리 원천 (돌봄) 원천 (IT/인프라)
트랙 DW helana_log/docs/tracks/disability-welfare.md —
트랙 DC helana_log/docs/tracks/dementia-care.md —
트랙 BL helana_log/docs/tracks/basic-livelihood.md —
대화록 helana_log/docs/dialogue/*.md (현재 1편+템플릿) —
솔루션 helana_log/docs/solutions/README.md (스케치 4종) helena_phone/care/* (돌봄 데몬 본체)

돌봄 데몬 본체 (helena_phone/care/):
- care-daemon.sh + care.conf — 돌봄 데몬 코어
- phone-health.sh — 건강 검진 (세션 시작 시 실행)
- tailscale-care-daemon* + tailscale-check.sh + start-*.sh — 원격 돌봄망
- tg.sh — 텔레그램 보고 무전기

⚠️ 소망 분리: radio-ticket-automation.md(라디오 초대권), s21-singing-ai-pipeline.md(노래 AI)는
돌봄이 아니라 소망(길 2) → S21로. 솔루션 카테고리에 넣지 않는다.

5. 실행 순서 (하나하나씩)

  • [ ] Step 1 — 빵꾸 삭제 (7편): 티스토리 삭제 API 확인 → 삭제.
  • [ ] Step 2 — IT 4편 S21 이동: reverse_fetch 원고 → galaxys21/helena_phone 원고로 재편 후 재발행.
  • [ ] Step 3 — 기존 카테고리 정리: IT(8글) + 사고흐름(0) → 4편 이동 후 비우고 삭제/보관.
  • [ ] Step 4 — 트랙 3종 발행: DW·DC·BL 원고 → 각 카테고리.
  • [ ] Step 5 — 대화록 발행: dialogue 원고 → 대화록 카테고리.
  • [ ] Step 6 — 솔루션 발행: 돌봄 데몬 스크립트를 “해설 원고”로 → 솔루션 카테고리.
  • [ ] Step 7 — 코드 커밋 정리: tistory-naver/ 웹페이지 코드 + create_categories.py 커밋.

6. 판단 기록 (왜 이렇게)

  • 기존 configs/ecosystem-map.json의 “tech/박씨캡처 리버싱”은 폐기 — Boss가 돌봄으로 정정.
  • “IT + 돌봄”의 정확한 정의 = 돌봄을 수행하는 IT(돌봄 데몬), 순수 기술 노트나 순수 스토리가 아님.
  • 그래서 솔루션 카테고리에는 care/ 데몬이 들어가고, 소망(라디오·노래 AI)은 들어가지 않는다.
