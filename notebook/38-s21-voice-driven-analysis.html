2. Voice-Driven OS — 장점

✅ 충분한 연산력

STT·LLM·API 전부 클라우드. 8GB RAM으로 Claude Code·Grok·Aider 동시 구동. 로컬은 경량 bash만.

✅ 배터리 지속성

화면 OFF + API 호출 위주. 상시 음성비서보다 효율적. 식당 노동 중 하루 OK.

✅ 경량성 (169g)

한 손에 들고 말하기 좋음. 이동·노동 중 실제 사용 검증. 덱스 모드로 데스크탑 전환.

✅ 비용 효율

중고 20만원. 최신폰 1/9. 실패 리스크↓ 배터리 교체 5~8만원.

3. Voice-Driven OS — 한계

❌ NPU 부재

로컬 LLM·온디바이스 STT 커스터마이징 불가. 하지만 API가 모든 걸 대체한다.

❌ 배터리 노화

5년 사용·~85% 용량. 장시간 녹화 시 급격 소모. 교체 가능하나 방수↓

❌ 발열 제약

Exynos 2100 발열↑ Playwright 장시간 시 쓰로틀링. 여름철 냉각 필요.

❌ 디스플레이 크기

6.2" 코드 리뷰 협소. 화면 녹화 시 고밀도 가독성↓ 덱스 모드 보완.

4. 핵심 인사이트

보이스 드리븐 운영의 역설: API 기반이면 구형이 오히려 낫다.
