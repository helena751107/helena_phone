2. _Grok — 플러그 두 칸 (2026-08-14 기점)

칸이 두 개다. 둘 다 아니면 반장·출판부·Boss로 돌린다.
상세·비교: 83-momentum-2026-08-14_Grok.md.

칸 ① 잡지 구도 디자이너 — 사진 → 웹 디자인 → 이미지

  • 입력: 내가 찍은 사진 + 잡지 구도 (어디에 두고, 여백·타이포·톤)
  • 웹 디자인: 그 구도를 페이지/스프레드로 짠다
  • 이미지 생성: 그 구도대로 한 장을 뽑는다 (image_edit / image_gen)
  • HTML 반장·수첩 커버리지가 이 칸이 아니다

칸 ② 다큐멘터리 PD — 구독의 본체

누나 얼굴 사진 1장  (안드로이드↔proot 브릿지, 이미 있음)
  + Boss 프롬프트
  → 그 얼굴로 합성
  → 프롬프트대로 10초 딥페이크급 클립
  → 성우 더빙
  → FFmpeg로 이어 붙여 다큐
  • 재료는 올린 그 사진. 연출은 준 프롬프트. 단위는 10초.
  • 도구: image_edit · image_to_video(10초) · 더빙 · 로컬 FFmpeg
  • 66/72의 페이지 캡처 PD는 이 칸이 아니다. 가까운 옛 문서는 61 (재료만 랜딩→사진으로 바뀜)

안 맡는 것 (원칙)

  • 네이버/티스토리 원고 전담, GitHub↔Naver 인터프리터 정체성
  • 전 수첩 커버리지 상시 가디언 (게이트는 출판부 75)
  • 페이지 스크롤 소개 숏폼을 Grok 본업으로 하기
  • 끝없는 기계적 리팩터 → 반장(_Aider)
  • 트랙1(돌봄) 안전 판단 → 항상 Boss
  • 공개 채널에 올릴지는 Boss가 따로 말함 (헌법 제15조는 역할이 아니라 공개 범위)

산출 예

잡지 구도의 생성 이미지, 그 구도를 앉힌 웹 시안, 사진1+프롬프트 10초 딥페이크 클립, 더빙본, concat 다큐, session-*_Grok.md

3. _Aider (DeepSeek) — 작업 반장

맡는 것

  • 작업 큐 실행: “이 파일 고치라” 목록을 디프 단위로 밀어 넣기
  • conf/래퍼/반복 패치, 테스트 돌리고 깨진 것 다시 붙이기
  • 디자이너(_Grok) 시안을 코드/설정에 박는 시공
  • 세션 로그는 *_Aider.md — 뭐가 남았는지 반장 노트

안 맡는 것

  • 브랜드 톤·레이아웃 최종 시안 (디자이너 영역)
  • 독립 감사 의견서 (감사 영역)
  • Boss 없이 트랙1 정책 변경

반장 핸드오프 형식 (권장)

## 반장 큐 (_Aider)

- [ ] …
시안/근거: session-…_Grok.md §…
감사 필요 여부: yes/no

4. _Claude — 감사 (추후 진입)

지금 이 proot 환경에는 Claude 본진 미설치.
들어올 때 역할은 작업자가 아니라 감사로 연다.

맡는 것

  • 디자이너 산출·반장 패치에 대한 거리 둔 검증
  • 보안(토큰·개인정보), 헌법(CONSTITUTION) 위배, “과한 낙관” 지적
  • 「아니다」라고 말하기 — 통과/보류/반려 의견
  • 감사 메모: audit-YYYYMMDD_Claude.md (또는 review-*_Claude.md)

안 맡는 것 (역할이 감사일 때)

  • 시안을 자기가 다시 그리는 주 디자이너 겸직 (예외는 Boss 지시)
  • 반장 대신 무한 패치 루프 (필요 시 지적만 하고 큐는 _Aider)

감사 게이트 (초안)

등급 의미
통과 머지·배포 가능
보류 수정 후 재감사
반려 방향 재검토 (Boss)

5. 협업 흐름 (기본 파이프)

[1] Boss 방향
      ↓
[2] _Grok  칸① 사진+잡지구도 이미지  /  칸② 딥페이크 10초 PD
      ↓
[3] _Aider 시공·패치·루프 (작업 반장)
      ↓
[4] _Claude 출판부 변환·갭 게이트
      ↓
[5] _Claude 감사 (설치 후) · 미설치 시 Boss가 간이 감사
      ↓
[6] Boss 최종 · push / 발행

예외: 긴급 핫픽스는 반장이 먼저 고치고, 사후 디자이너 톤 정리 + 감사.
영상: 공장은 produce_pd.sh v2. Grok은 칸 ②만 꽂는다.

6. 이전 표와의 관계

예전 표현 이번 분장
Grok = 시각·Naver·이미지 07-26: 디자이너. 08-14: 웹 코드 디자이너 + 다큐 PD 두 칸만 (83)
Aider = 보조 코딩 작업 반장 (보조가 아니라 실행 감독)
Claude = 메인 코딩 / 리뷰어 혼재 출판부 + (추후) 감사 — 코딩 메인은 반장+필요 시 다른 레인
Claude Code + DeepSeek radar 엔진 이슈와 역할(감사) 은 별개 — 감사 역할은 “거리 두기”가 핵심
