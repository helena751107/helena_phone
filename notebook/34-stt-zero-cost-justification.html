S21 Phone — STT 기반 0원 풀스택 AI 워크스테이션 정당화 문서

버전 1.0 | 2026.07.26 | Boss + Claude Code

1. 이게 가능한가? — 가능하다. 증거가 여기 있다.

질문 답 증거
키보드 없이 가능한가? 100% STT 41커밋·96파일·11,727줄 전부 음성으로
PC 없이 가능한가? 중고폰 1대로 Galaxy S21 (2021년 출시·중고가 20만원)
돈 들지 않는가? 월 55,000원 DeepSeek $0 + Grok 45,000원 = AI 3종 풀스택
초보자가 가능한가? 1줄 설치 curl -sL .../install.sh | bash
혼자 가능한가? AI 3종이 분업 Claude Code(코드) + Grok(시각) + Aider(보조)
지속 가능한가? 핸드오프 설계 돌봄 데몬은 AI 의존성 제로

2. 이걸 가능하게 하는 기술 스택 — 전부 무료

입 (STT 음성)
  │
  ▼
Android 음성인식 → 클립보드 → Termux
  │
  ▼
뇌 (AI 에이전트 3종·월 55,000원)
├── Claude Code → 코드·문서·git·API
├── Grok CLI   → 이미지·영상·Naver
└── Aider      → 반복 작업·패치
  │
  ▼
손 (플랫폼·전부 무료)
├── GitHub      → 코드 저장·$0
├── GitHub Pages → 웹 호스팅·$0
├── YouTube     → 영상 CDN·$0
├── Naver       → 블로그·한국 독자·$0
├── Tistory     → 업무일지·$0
├── Discord     → 커뮤니티·$0
└── Telegram    → 내부 보고·$0

단 한 가지 유료: Grok 45,000원/월. 이미지·영상 생성용.
나머지 전부 $0. 합계 월 55,000원 — 커피값으로 풀스택 AI 스튜디오.

3. 왜 이게 정당한가 — 3개의 증명

증명 ①: 제약 속에서 실제로 구축했다

이 프로젝트의 작성자는:
- 안드로이드 폰 1대
- 100% STT 음성입력 (키보드 0회)
- 식당 육체노동 병행 (풀집중 불가능)
- 돌봄 가정 (조현병 누나·치매 어머니)

이 제약들은 “할 수 없는 이유”가 아니라 “이 제약에서도 가능하다는 증거” 다.

증명 ②: API가 없는 플랫폼도 우회하지 않고 다룬다

티스토리 API 2024년 종료. 네이버 API 없음.
→ Paste Pipeline: AI가 원고 작성 → TG 배달 → 사람이 복사붙여넣기 (5분)

이건 “플랫폼 정책을 위반하는 자동화”가 아니다.
플랫폼이 의도한 사용법을 그대로 따르면서 AI의 생산성을 결합한 방식이다.

증명 ③: 핸드오프를 전제로 설계됐다

이 시스템의 주인은 작성자가 아니다. 큰누나다.
작성자는 대필작가-간병인으로서, 누나가 언젠가 이 폰으로
STT만으로 시스템을 스스로 운영할 수 있게 하는 것이 목표다.

CONSTITUTION.md 제7조: “핸드오프가 곧 성공이다.”

4. 차별점 — 액자식 뫼비우스 띠

일반적인 국책·교육 콘텐츠:
→ 특권층이 약자를 “도와주는” 시혜적 프레임

이 프로젝트:
→ 당사자가 직접 만든다
→ 만드는 과정 자체가 콘텐츠다
→ 콘텐츠의 첫 학습자도 당사자(누나)다
→ 가르치는 사람 = 배우는 사람 = 같은 제약 조건

이게 액자식 메타 구조다.
이런 구조의 실증 사례는 공개된 바가 거의 없다.

5. 주요 수치

지표 값
구축 시간 36시간
커밋 41회
코드+문서 11,727줄 (국판 500페이지)
월 운영비 ~55,000원
입력 방식 100% STT 음성
플랫폼 25개 계정·7개 워크센터
AI 에이전트 3종 (Claude Code·Grok·Aider)
설치 소요 curl 1줄 → 10분

6. 결론

“말만 할 수 있다면, 누구나 풀스택 AI 미디어 플랫폼을 운영할 수 있다.”

이건 이론이 아니라 실증이다.
중고폰·무료 도구·음성입력만으로 36시간 만에 구축된
생태계가 그 증거다.

가르치는 사람과 배우는 사람이 같은 제약을 공유할 때,
교재는 설명서가 아니라 살아있는 증거가 된다.
