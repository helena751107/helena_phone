## 설계 목표

트랙 1은 **AI 의존성 없이** 작동하는 경량 데몬이다. Claude Code 세션이 죽어도, DeepSeek API가 다운돼도, proot Ubuntu가 깨져도 **위치·배터리·이상 신호 보고는 절대 멈추지 않아야 한다.**

---

## 아키텍처

```
Termux (Android 네이티브, proot 위가 아님)
│
├── care-daemon.sh        ← 크론으로 매 N분 실행 (순수 bash)
│   ├── termux-battery-status    → 배터리 잔량/온도/충전상태
│   ├── termux-location          → GPS 위치 (network fallback)
│   ├── termux-telephony-device  → 셀룰러 신호 + 네트워크 타입
│   └── termux-notification      → 로컬 알림 (비상시)
│
├── care-reporter.sh      ← 수집된 데이터 → 텔레그램 DM 전송
│   └── curl → Telegram Bot API
│       ├── TG_CHAT_HELENA   (헬레나)
│       └── TG_CHAT_PASTOR   (목사님)
│
└── care-state.json        ← 상태 저장 (이전값과 비교해 이상 감지)
    ├── last_battery_pct
    ├── last_location
    ├── last_report_time
    └── anomaly_flags
```

### 왜 proot Ubuntu 위가 아닌가

| proot Ubuntu | Termux 네이티브 |
|-------------|-----------------|
| DeepSeek/CC 세션이 죽으면 같이 멈춤 | CC와 무관하게 독립 실행 |
| Python venv, node 등 의존성 무거움 | 순수 bash + curl + termux-api |
| pip 빌드 실패 등 변수 많음 | 의존성 거의 없음 |
| 실험적 — 깨지도록 설계됨 | 보수적 — 안 깨지도록 설계됨 |

## 감지 항목

### 1. 배터리 이상
| 조건 | 액션 |
|------|------|
| 잔량 < 15% (방전 중) | 즉시 보고 + "충전 필요" 알림 |
| 잔량 급감 (1시간 내 30% 이상 하락) | 이상 보고 |
| 온도 > 45°C | 즉시 보고 + "폰 과열" 경고 |
| 충전 중 → 비충전 전환 (외출 감지) | 정기 보고에 포함 |

### 2. 위치 이상
| 조건 | 액션 |
|------|------|
| GPS 2시간 이상 무응답 | 이상 보고 |
| 위치가 평소 반경 500m 밖 (집 이탈) | 선택적 보고 (외출 정상일 수 있음) |
| 6시간 이상 위치 변동 없음 | 웰니스 체크 ("움직임 없음") |

### 3. 활동 패턴
| 조건 | 액션 |
|------|------|
| N시간 이상 화면 ON 이벤트 없음 | 웰니스 체크 |
| N시간 이상 통화/문자 없음 | 참고 정보 (정상일 수 있음) |
| 새벽 시간대 비정상 활동 | 이상 보고 |

### 4. 연결성
| 조건 | 액션 |
|------|------|
| WiFi RSSI 급감 (연결 끊김) | 경고 |
| 셀룰러 신호 0 | 경고 (통화 불가 상태) |
| 인터넷 연결 끊김 (ping 실패) | 로컬 알림 + 복구 시 재보고 |

## 보고 체계

### 정기 보고 (매 1시간)
```
🟢 [정기] 14:00
배터리: 68% / 37.6°C / 충전중
위치: 서울시 ○○구 (GPS)
WiFi: U+NetFA1B (-47dBm)
상태: 정상
```

### 이상 보고 (즉시)
```
🔴 [이상] 15:23
배터리 급감: 45% → 18% (40분)
현재 위치: 서울시 ○○구
마지막 활동: 14:05
즉시 확인 필요!
```

### 웰니스 체크 (미응답 시 에스컬레이션)
```
🟡 [웰니스] 16:00
6시간 동안 위치 변동 없음.
배터리 정상(72%).
→ 누나에게 확인 연락 권장.
```

## AI 통합 지점 (선택적, 분리된 채널)

- Claude Code는 `care-state.json`을 읽어서 대시보드 표시 가능
- CC 세션은 `care-daemon.sh`에 의존하지 않음 (단방향 읽기)
- CC가 죽어도 데몬은 독립적으로 계속 실행
- CC가 care-state.json을 통해 이상 패턴 학습 가능 (장기)

## 주의사항

- **절대 proot Ubuntu 안에서 실행하지 않는다.** Termux 네이티브 crontab만 사용.
- **AI(Claude Code)는 소비자일 뿐, 의존성이 아니다.**
- 위치 데이터는 텔레그램 DM으로만 전송. 공개 채널, GitHub, Discord 공개방으로 새지 않게.
- 119 자동 신고는 오탐 위험이 있으므로 1차/2차 사람 확인 후 수동 실행.
