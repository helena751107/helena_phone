남들한테 보여줄 만한 솔루션 8개

① 하이엔드 클래식 웹진 (helena-piano)
Gramophone/DG/객석 스타일 음악 잡지를 티스토리 위에 구축. markdown→잡지 HTML 렌더러, <audio>·<figure> 임베디드, 드롭캡·풀쿼트·히어로, 두 레인(스튜디오/잡지) 11편. “폰으로 만든 음악 잡지”.

② S21 액자식 시그니처 디자인 (5블로그 공통)
베젤·컨투어컷 카메라·펀치홀·갤럭시 스타필드를 CSS로 재현. 블로그마다 테마 변수화(색+스타필드) + API 자동 주입(apply_layout.py).

③ PD Pipeline V10 — URL→숏폼 영상 자동화
웹페이지를 “읽고” 섹션별 캡처 → 연출 자동 결정 → Ken Burns + CNN식 ASS 자막 + Edge TTS 더빙 → xfade + BGM 사이드체인. “독해와 편집 판단” 기반 영상 공장.

④ 출판 파이프라인 (출판부 · md→HTML 자동화)
수첩 → 웹진 HTML 자동 변환 + 커버리지 게이트(gap>0 = 배포 차단) + CI. GitHub가 SSOT, 티스토리는 전시 복제본.

⑤ 티스토리 발행 엔진 (Playwright 헤드리스)
로그인 세션 영속화 + tinymce setContent+save + 카테고리 정밀 배치 + 댓글 강제 차단 + 일일한도(15개/일) 감지 + 공개/비공개 전환. 원고 110+ 건을 자동 발행.

⑥ 디렉터 게이트 (업로드 전 품질 심사)
원고 심사(PASS/REVISE/HOLD) + 제목·태그 확정 + 8Part·31Ch 카테고리 배선. “아무거나 안 올리는” 품질 레이어.

⑦ AI 성우 목소리 클론 (RVC 3음색)
helena · parksy · taesoon. 백서·기술명세·더빙 표준까지 문서화. 누나 육성으로만 재현 가능한 “로고급” 자산.

⑧ 저사양 폰 AI 생존 플랫폼
3년 된 폰(Termux+proot)에 Claude Code + Aider + Grok + phone-mcp 18도구. STT 음성입력, Tailscale 원격접속, health 자가검진.

솔직한 미완

  • NPU/GPU 가속 — Termux NDK 크로스컴파일 “설계만” 있고 S21 실측 0회. 이 프로젝트의 유일한 기술벽.
  • 품질 레이어 반쪽 — 디렉터 게이트·카테고리 매핑은 코드로만 있고, 블로그 카테고리 21개 생성·day-1 백필은 남음.

한 줄: 3주 동안 “배선 인프라”는 끝냈고, 남들한테 보여줄 건 이미 잡혀 있다 — 목소리 클론 · 110+페이지 웹진 · URL→영상 자동화 · 티스토리 자동발행 엔진. 남은 건 품질 마감과, 유일하게 안 풀린 NPU 벽 둘뿐.
