## 3. 왜 이게 정당한가 — 3개의 증명

### 증명 ①: 제약 속에서 실제로 구축했다

이 프로젝트의 작성자는:
- 안드로이드 폰 1대
- 100% STT 음성입력 (키보드 0회)
- 식당 육체노동 병행 (풀집중 불가능)
- 돌봄 가정 (조현병 누나·치매 어머니)

이 제약들은 "할 수 없는 이유"가 아니라 **"이 제약에서도 가능하다는 증거"** 다.

### 증명 ②: API가 없는 플랫폼도 우회하지 않고 다룬다

티스토리 API 2024년 종료. 네이버 API 없음.
→ Paste Pipeline: AI가 원고 작성 → TG 배달 → 사람이 복사붙여넣기 (5분)

이건 "플랫폼 정책을 위반하는 자동화"가 아니다.
**플랫폼이 의도한 사용법을 그대로 따르면서 AI의 생산성을 결합한 방식**이다.

### 증명 ③: 핸드오프를 전제로 설계됐다

이 시스템의 주인은 작성자가 아니다. **누나**다.
작성자는 대필작가-간병인으로서, 누나가 언젠가 이 폰으로
STT만으로 시스템을 스스로 운영할 수 있게 하는 것이 목표다.

CONSTITUTION.md 제7조: "핸드오프가 곧 성공이다."

## 4. 차별점 — 액자식 뫼비우스 띠

일반적인 국책·교육 콘텐츠:
→ 특권층이 약자를 "도와주는" 시혜적 프레임

이 프로젝트:
→ 당사자가 직접 만든다
→ 만드는 과정 자체가 콘텐츠다
→ 콘텐츠의 첫 학습자도 당사자(누나)다
→ 가르치는 사람 = 배우는 사람 = 같은 제약 조건

**이게 액자식 메타 구조다.**
이런 구조의 실증 사례는 공개된 바가 거의 없다.
