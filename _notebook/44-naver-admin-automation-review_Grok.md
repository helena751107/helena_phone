## 4. 쓰레기통에서 건진 방법 (우선순위)

### A. 사람 1회 로그인 → storageState (최강 반쪽)

```
headed Chrome/Playwright
  → 네이버 로그인 (캡차는 사람)
  → storageState 저장 (login.cjs 이미 있음)
  → 이후 headless/headed 재사용
```

- 이미 있음: `tistory-naver/login.cjs`, `post.cjs`, `post.py`
- 매일 비번 자동 입력 ❌ → **쿠키 수명 끝날 때만 사람 재로그인**

### B. 카테고리 “추가” 1회 스크립트 (권장 도전 범위)

PC 경로 (공식 고객센터):

```
관리 → 메뉴·글·동영상 관리 → 메뉴 관리 → 블로그
→ [카테고리 추가] → 이름·공개·주제분류 → 저장
```

Playwright 전략 (좌표 아님):

1. 저장된 쿠키로 admin URL 진입  
2. `get_by_text("카테고리 추가")` 클릭  
3. 이름 입력 필드 fill  
4. 확인/저장  
5. 스크린샷 + 실패 시 TG 알림 → 사람이 이어서

**드래그로 2단/순서** 는 1차 범위에서 **제외**. 사람은 5분, 봇은 이틀 삽질.

### C. 네트워크 가로채기 (있으면 잭팟)

카테고리 추가 한 번 수동으로 하면서 DevTools Network 캡처:

- XHR에 `category` / `menulist` 류 요청 있으면  
- 같은 쿠키로 `fetch` 재현 → UI 클릭 불필요  
- **없으면** B로 후퇴

### D. 글 발행 시 카테고리만 지정 (이미 있음)

`tistory-naver/post.py`:

```python
select#categoryId / select[name='categoryId']
→ select_option(label=cat)
```

카테고리 **이름만 미리 사람/1회봇이 만들어 두면**, 이후 글봇·또는 손발행에서 선택만 하면 됨.

### E. MetaWeblog / 글쓰기 API (레거시 확인 과제)

- 관리 → 글쓰기 API 설정 → 암호 발급  
- 외부 툴 newPost 시 **기본 카테고리 프리셋** 가능 (문서상)  
- 카테고리 **목록 생성** 용이 아님  
- 2026년 계정별로 막혀 있을 수 있음 → helena1975에서 **1회 프로브**만

### F. 주간 퀼트 발행 (정본 유지)

```
TG 패키지 → 서식 불러오기 → 손 붙여넣기 → 발행
```

여기 Playwright 넣는 순간 **수공예 퀼트 브랜드 자살**.  
기술적으로 가능해도 **전략적으로 안 함**.

### G. 상업 “슈퍼봇” / 멤버십 매크로

- 커뮤니티에 많음  
- 계정 제재·스팸 지수·브랜드 오염  
- **쓰레기통에 도로 넣음**
