**보이스 드리븐 운영에서는,  
구형 플래그십이 오히려 엔진이 될 수 있다.**  
근거는 감이 아니라 표입니다.

제 손의 기기는 갤럭시 S21, 모델 G991N.

램 팔 기가, 배터리 사천, 무게 백육십구 그램.  
그리고 **엔피유는 없습니다.**  
로컬에서 큰 언어 모델을 돌리겠다는 용도가 아닙니다.  

이 숫자만 외우셔도 오늘 강의 반은 갑니다.  
이십만, 백육십구 그램, 엔피유 없음.

# SLIDE 03 — 보이스 드리븐이란

### 칠판
```
Voice-Driven = 

입  →  STT(음성→글)
뇌  →  에이전트(API)
손  →  플랫폼(배포·발행)

키보드 최소 · 말이 입력
```

### 대본
여기서 보이스 드리븐을 짧게 정의합니다.  

입은 음성 인식으로 글이 되고,  
뇌는 클로드 코드, 그록, 에이더 같은 에이전트가 API로 생각하고,  
손은 깃허브, 페이지스, 유튜브, 네이버, 텔레그램으로 나갑니다.  

키보드를 안 친다는 뜻이 아니라,  
**주 입력이 말**이라는 뜻입니다.  
이 구조에서는 무거운 연산이 폰 안이 아니라 **구름**에 있습니다.

# SLIDE 04 — 역설 (핵심 칠판)

### 칠판
```
★ 보이스 드리븐의 역설

API가 주력이면
로컬 성능 < 네트워크 · 배터리 · 휴대성

S21이 아직 이기는 축
· 무게 169g
· 가격 ~20만
· 수리 쉬움
· 하루 API 루프 가능한 배터리
```

### 대본
핵심입니다. 칠판에 별표 치세요.  

**에이피아이가 주력이면,  
로컬 성능보다 네트워크, 배터리, 휴대성이 엔진입니다.**  

에스이십일은 시피유에서 최신폰에게 집니다.  
엔피유는 아예 없습니다.  
그런데 보이스 드리븐 채점표에서는  
**가벼운 무게, 싼 가격, 고치기 쉬움**이 올라갑니다.  

실패해도 이십만 원.  
최신 플래그십 실패는 백팔십만 원.  
실험 비용이 아홉 배 차이 납니다.  
이게 전략입니다.

# SLIDE 05 — 비교표 (말하면서 교재 탭 전환 가능)

### 칠판
```
항목          S21        최신폰      Voice 중요도
API 속도      동일       동일        무관(클라우드)
STT 정확도    동일       동일        무관
휴대성        169g 승    무거움      ★★★
비용          20만 승    180만       ★★★
수리          쉬움 승    어려움      ★★
온디바이스AI  불가       가능        API로 대체
배터리        양호       더 좋음     상황별
```

### 대본
표로 보겠습니다.  

에이피아이 응답 속도— 둘 다 클라우드면 같습니다.  
에스티티 정확도— 구글 음성이면 기기 차이가 거의 없습니다.  

그런데 한 손으로 들고 식당에서, 이동 중에 말하면  
**백육십구 그램**이 이깁니다.  
비용은 말할 것도 없고,  
수리는 구형이 쉽습니다.  

온디바이스 에이아이는 최신이 이깁니다.  
우리는 **에이피이로 대체한다**고 설계했습니다.  
그래서 ‘없다’가 곧 ‘실패’가 아닙니다.

# SLIDE 06 — 장점 다섯

### 칠판
```
S21 장점 (Voice 운영)

1 연산: API면 충분 · 8GB로 Termux+proot
2 배터리: 화면 끄고 API 위주 → 하루
3 무게: 169g · 한 손·노동 중 사용
4 비용: 20만 · 배터리 교체 5~8만
5 성숙: Android 15 · Termux API · 안정
```

### 대본
장점만 다섯 줄로 정리합니다.  

하나, 연산. 에이전트가 에이피이면 로컬은 터먹스와 프로옷만 돌려도 됩니다.  
둘, 배터리. 화면을 끄고 호출 위주면 사천 밀리암페어로 하루를 버팁니다.  
셋, 무게. 실제로 들고 말합니다.  
넷, 비용. 망해도 이십만. 배터리만 갈면 오만에서 팔만.  
다섯, 소프트웨어가 이미 익었습니다. 초기 불량 구간이 아닙니다.

# SLIDE 07 — 한계 다섯 (정직)

### 칠판
```
S21 한계 → 우회

NPU 없음     → API · 클라우드 STT
배터리 노화  → 교체 · 녹화 시간 조절
발열         → 장시간 Chromium 주의
WiFi 6       → 4K 장시간만 체감
6.2" 화면    → DeX · 외부 모니터
```

### 대본
광고가 아닙니다. 한계도 말합니다.  

엔피유 없음— 로컬 엘엘엠 안 합니다. 에이피이.  
배터리 늙음— 갈아 끼웁니다. 화면 녹화는 짧게.  
발열— 플레이라이트 하루 종일은 무리.  
와이파이 육— 사케이나 일반 업로드는 충분, 사케이에 가까운 장시간만 답답.  
화면 작음— 덱스나 모니터.  

**완벽한 폰이 아니라, 이 제약 안의 최적 엔진**입니다.

# SLIDE 08 — 입 뇌 손 스택

### 칠판
```
입  음성인식 → 클립보드 → Termux
뇌  cc 코드 · gr 시각 · ds 패치
손  GitHub · Pages · YT · Naver · TG

월 구조 예: 런타임 $0 축 + 구독 1레인
= 풀스택 미디어 파이프
```

### 대본
흐름을 외우세요. **입, 뇌, 손.**  

입은 말이 글이 되어 터먹스로 들어갑니다.  
뇌는 에이전트 셋이 분업합니다.  
코드와 깃, 시각과 네이버 드래프트, 반복 패치.  
손은 무료 플랫폼으로 나갑니다.  

호스팅 상당수는 공짜에 가깝습니다.  
유료는 보통 구독 하나 수준으로 설계합니다.  
이게 ‘커피값으로 스튜디오’라는 말의 정체입니다.  
다음 강에서 스택을 깔아 보겠습니다.

노트북— 되지만 무겁고 비쌉니다.  

에스이십일은 **말하면서 풀스택을 운영하는**  
거의 유일한 일상 폼팩터입니다.  
그래서 이 시리즈가 폰을 붙잡습니다.
