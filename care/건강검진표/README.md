# 📋 S21 라인 — 건강검진표 보관소

> **목적**: 갤럭시 S21(누나 폰)이 "저사양 검증 라인"이면서 동시에 "실사용 폰"일 때,
> 그 건강 상태(배터리/발열/메모리/부하)를 날짜별로 기록하는 공식 보관소.
> 이 기록이 **표준원가 + 통과 기준 + 가동 조건** 설계의 근거 데이터가 된다.

## 보관 규칙
- 날짜 폴더: `YYYY-MM-DD/` (예: `2026-08-24/`)
- 파일 형식: 마크다운 (원시 데이터는 `raw/`에 함께)
- 기록 항목: 하드웨어 · 배터리 · 프로세스 · 라인설비감사
- 기준값은 README 하단에서 갱신 (측정할 때마다)

## 검증 실행원가 규칙 (초안 — 미확정)
```
라인 대기 표준원가  = 2%/hr
검증 실행 실행원가  = 작업당 배터리 % (아직 측정 안 됨, 이후 기록)
가동 조건 제안      = 충전 중 + 배터리 ≥ 80% 에서만 검증 / 실사용 시간대(09~22시) 스톱
```
> ⚠️ 이 규칙은 초안. 라인 가동 룰로 확정되려면 실측 데이터 더 쌓아야 함.
