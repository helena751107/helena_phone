판정

❌ WSL2 + Aider 확장은 포기

Celeron 3855U + 4GB RAM은 Windows 10 혼자 돌리기에도 빠듯하다. WSL2는 Hyper-V 기반 VM을 띄우는데 최소 2GB가 필요하고, 그러면 Windows에 남는 건 2GB. 여기서 Aider + Git + Python을 띄우면? 스왑 지옥. 하루 종일 멈춘다.

✅ S21이 메인 컴퓨터다

Exynos 2100은 Celeron 3855U보다 싱글코어 2배, 멀티코어 4배 빠르다. RAM도 2배 많고 더 빠르다. 이 폰은 이미 리눅스를 돌리고 있다. PC 없이도 풀스택이다. 여기에 GitHub Actions의 공짜 2000분/월 Linux 러너를 더하면, 정기 작업(빌드·RSS·체크)은 GitHub가 대신 돌려준다.

이미 돌아가고 있는 것에 GitHub Actions 자동 빌드 파이프만 더하면, 공짜 클라우드 서버랑 다를 게 없다.

실행 로드맵

1단계: GitHub Actions → MD→HTML 자동 빌드 (바로)

Push할 때마다, 그리고 cron으로 매일 새벽. _notebook/*.md → notebook/*.html 자동 변환.

.github/workflows/build-webzine.yml
name: Build Webzine
on:
  push:
    paths: ['_notebook/**.md', 'scripts/build_webzine.py']
  schedule:
    - cron: '0 21 * * *'  # 매일 아침 6시 (KST)
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.12' }
      - run: pip install markdown
      - run: python scripts/build_webzine.py
      - run: |
          git config user.name "GitHub Actions"
          git config user.email "actions@github.com"
          git add notebook/ && git diff --staged --quiet || git commit -m "build: auto webzine"
          git push

2단계: RSS → helana_log 자동 동기화

매 6시간마다 5개 티스토리 RSS 긁어서 helana_log/기자/ 폴더로 저장. 지금 수동으로 도는 tistory_sync.sh를 Actions cron으로.

3단계: 상태 대시보드 (정적 JSON → Pages)

모든 레포의 마지막 커밋·Actions 성공여부·RSS 동기화 상태를 정적 JSON으로 만들어 Pages에 표시.

그래도 PC 연결이 필요하면 — Thin Client 모드

PC에 Python·Aider·WSL 전부 포기. Tailscale + SSH만. PC의 유일한 가치는 큰 화면과 키보드다.

방향을 거꾸로: PC → Phone

누나 PC (Celeron 4GB) S21 Phone (Exynos 8GB) │ │ │ Tailscale │ Tailscale │ Windows Terminal │ Claude Code │ │ Aider │ │ Git repos │──── ssh → 100.x.x.x (폰 Tailscale IP) ────────▶│ DeepSeek API │ │ │ PC는 키보드+화면만. 모든 작업은 폰에서. │

PC에서 PowerShell로:

PowerShell
# PC → Phone 역방향 SSH
ssh root@100.x.x.x  # 폰의 Tailscale IP

붙은 다음엔 cc 또는 ds 입력. 폰의 AI 에이전트를 PC 화면으로 쓰는 거다.
