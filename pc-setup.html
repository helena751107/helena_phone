🏠 집에 있는 PC랑 연결하기

깡통 PC + 누나 폰 = 원격 AI 워크스테이션. 복사붙여넣기 6단계면 끝.

전체 흐름 — 한눈에

누나 폰 (S21 + Termux) │ │ Tailscale mesh VPN │ ssh 사용자명@100.x.x.x ▼ 집PC (Windows 10) │ Windows OpenSSH Server │ Tailscale Windows Native │ │ wsl ← 한 마디로 우분투 진입 ▼ WSL2 Ubuntu │ Aider + DeepSeek │ Git repos │ 빌드·서버·Docker
핵심: Tailscale은 Windows 네이티브에만 깐다. WSL 안에 깔면 네트워크 꼬여서 폰에서 못 찾는다. SSH도 Windows OpenSSH로 받는다. 폰 → Windows SSH → wsl → Aider. 딱 한 hop.

1 PC — Tailscale 설치

PowerShell 관리자 권한으로 열고:

PowerShell — 관리자
winget install tailscale.tailscale

설치 끝나면:

PowerShell
tailscale up

브라우저 창 뜨면 로그인. 폰이랑 반드시 같은 계정으로.

2 PC — Windows SSH 서버 켜기

같은 관리자 PowerShell에서:

PowerShell — 관리자
Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd
Set-Service -Name sshd -StartupType 'Automatic'

이제 PC가 SSH 연결을 받을 수 있는 상태가 된다. sshd는 윈도우 부팅할 때마다 자동으로 켜진다.

3 PC — Tailscale IP 확인 (적어두기)

PowerShell
tailscale ip -4

출력되는 IP(100.x.x.x)를 폰에 적어둔다. 이게 집PC의 Tailscale 주소다.

4 폰 — Tailscale + SSH 설치

Termux 앱 열고 겉에서 (~ $ 프롬프트, proot 안 아님):

Termux 겉 — pkg
pkg install -y tailscale openssh
tailscale up

PC랑 같은 계정으로 브라우저 인증.

5 폰 → PC SSH 접속 테스트

Termux — ssh
ssh [윈도우_사용자명]@[③에서_적은_IP]

윈도우 로그인 비번 물으면 입력. 붙으면 PowerShell 또는 CMD 화면이 뜬다.

예: ssh boss@100.72.145.88

6 우분투 + Aider로 점프

⑤에서 SSH로 붙은 PowerShell/CMD에서:

SSH 세션 안 — Windows
wsl
cd ~/work
aider --model deepseek/deepseek-v4-pro

wsl 한 마디면 우분투로 들어간다. 거기서 aider 치면 끝.

참고: WSL·Aider 최초 설치 (PC 처음 한 번만)

PC가 완전 깡통이면 이것부터. PowerShell 관리자로:

WSL2 + Ubuntu 설치

PowerShell — 관리자
wsl --install -d Ubuntu

재부팅 후 Ubuntu 터미널 열어서 사용자명·비번 설정.

Ubuntu에 Aider + DeepSeek 설치

WSL Ubuntu bash
# 기본 패키지
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential git curl wget python3 python3-pip pipx
pipx ensurepath

# Aider
pipx install aider-chat

# DeepSeek API 키 등록
cat >> ~/.bashrc << 'EOF'
export DEEPSEEK_API_KEY="여기에_API_키_입력"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
export AIDER_MODEL="deepseek/deepseek-v4-pro"
EOF
source ~/.bashrc

# Git 레포 클론
mkdir -p ~/work && cd ~/work
git clone --recurse-submodules https://github.com/helena751107/helena_phone.git

# Claude 행세 방지 설정
curl -o ~/.aider.model.settings.yml \
  https://raw.githubusercontent.com/helena751107/helena_phone/main/configs/aider.model.settings.yml

# ds 래퍼
mkdir -p ~/bin
cat > ~/bin/ds << 'DSEOF'
#!/bin/bash
REPO="${REPO:-$HOME/work/helena_phone}"
MODEL="${AIDER_MODEL:-deepseek/deepseek-v4-pro}"
cd "$REPO" || exit 1
aider --model "$MODEL" \
  --model-settings-file ~/.aider.model.settings.yml \
  --edit-format diff --chat-language Korean \
  --no-auto-commits --dark-mode --pretty "$@"
DSEOF
chmod +x ~/bin/ds
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc

echo "✅ 설치 완료. ds 입력하면 Aider 시작."

폰 alias — 한 줄로 PC 제어

폰의 ~/.bashrc (proot 안)에 추가:

Phone — ~/.bashrc (proot Ubuntu)
# ⚠️ PC_IP, PC_USER는 실제 값으로 바꿀 것
export PC_IP=100.x.x.x        # ③에서 확인한 Tailscale IP
export PC_USER=사용자명        # 윈도우 로그인 계정

alias pc="ssh ${PC_USER}@${PC_IP}"
alias pc-wsl="ssh ${PC_USER}@${PC_IP} -t wsl"
alias pc-ds="ssh ${PC_USER}@${PC_IP} -t 'wsl ~/bin/ds'"
alias pc-status="ssh ${PC_USER}@${PC_IP} -t 'wsl bash -c \"cd ~/work/helena_phone && git status --short\"'"
alias pc-push='git push && ssh ${PC_USER}@${PC_IP} -t "wsl bash -c \"cd ~/work/helena_phone && git pull --recurse-submodules\""'

# 사용법:
# pc       → Windows SSH 접속
# pc-wsl   → 바로 WSL Ubuntu 진입
# pc-ds    → 바로 Aider 실행
# pc-push  → push하고 PC에도 pull

✅ 통과 기준

⑤에서 SSH 접속 성공 → PowerShell/CMD 화면 뜸
⑥에서 wsl → aider 화면 뜸 → DeepSeek 응답 옴

이제 폰에서 ssh 한 줄이면 집 PC의 Aider까지 원격으로 부려먹을 수 있다.
