왜 PC인가

S21 폰만으로도 풀스택 워크스테이션이 돌아간다. 하지만:

  • 빌드·컴파일 — 폰에서 돌리면 느리고 배터리 먹음
  • Docker·서버 — proot Ubuntu에선 제한적
  • 멀티태스킹 — PC 화면이 훨씬 편함
  • GPU·대용량 — 모델 실행, 영상 처리
핵심: Phone = 감사·기획 (Claude Code). PC = 작업반장·시공 (Aider).
Tailscale로 묶고 SSH로 Phone에서 PC를 원격 제어한다.

1단계 Aider에게 전체 셋업 위임

아래 프롬프트를 통째로 복사해서 Aider에 붙여넣기.

Aider가 11단계 전체를 알아서 실행한다: Tailscale → WSL → SSH → Git → ds 래퍼 → 연결 테스트.

Aider 부트스트랩 프롬프트 — 복사해서 Aider에 붙여넣기
너는 Windows 10 + WSL2 Ubuntu 개발환경을 셋업하는 작업반장이다.
지금부터 내가 시키는 모든 것을 순서대로 실행해라.
필요한 명령어는 직접 실행하고, 안 되는 건 대안을 찾아서 해결해라.

--- 작업 목록 ---

[1] Tailscale 설치 + 로그인
- https://tailscale.com/download/windows 에서 다운로드 + 설치
- 설치 후 tailscale up 실행, 로그인 URL 출력
- 나한테 "여기 로그인해" 하고 URL 던져줘

[2] Tailscale 상태 확인
- tailscale status 로 PC의 Tailscale IP 확인
- 이 IP를 PC_IP 변수로 기록

[3] WSL2 설치 + Ubuntu
- PowerShell(관리자): wsl --install -d Ubuntu
- 재부팅 필요하면 말해줘
- Ubuntu 초기 사용자/비번 설정

[4] WSL 기본 셋업
- WSL Ubuntu 진입해서:
  sudo apt update && sudo apt upgrade -y
  sudo apt install -y build-essential git curl wget python3 python3-pip pipx openssh-server
  pipx ensurepath

[5] WSL에 Aider 설치
- pipx install aider-chat
- 테스트: aider --version

[6] DeepSeek API 키 설정
- Windows 환경변수: DEEPSEEK_API_KEY=여기에_API_키_입력
- Windows 환경변수: ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
- WSL ~/.bashrc에도 똑같이 추가

[7] WSL SSH 서버
- sudo service ssh start
- Windows 방화벽: Tailscale 인터페이스 22번 포트 허용

[8] Phone SSH 키 등록
- WSL의 ~/.ssh/authorized_keys에 다음 공개키 추가:
  ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIG5ohGtm3SbeKQzFe2glSRlIAwLurJJsiiHRhYn0R9L5 s21-phone-20260805
- chmod 600 ~/.ssh/authorized_keys

[9] Git 레포 클론 (WSL)
- mkdir -p ~/work && cd ~/work
- git clone --recurse-submodules https://github.com/helena751107/helena_phone.git

[10] ds 래퍼 설치 (WSL + Windows 양쪽)

WSL (~/bin/ds):
```
#!/bin/bash
REPO="${REPO:-$HOME/work/helena_phone}"
MODEL="${DEEPSEEK_MODEL:-deepseek/deepseek-v4-pro}"
cd "$REPO" || exit 1
echo "🔧 ds (WSL) — Aider + DeepSeek (${MODEL})"
aider --model "${MODEL}" --no-auto-commits --chat-language Korean --dark-mode "$@"
```

Windows (C:\Users\사용자\bin\ds.bat) — 같은 기능

[11] 전체 연결 테스트
- Phone에서 WSL로 SSH: ssh 사용자@PC_IP "echo 연결OK"
- WSL에서: ds "이 레포 구조 설명해줘"
- Windows에서: ds "현재 디렉토리 파일 목록"

DeepSeek API 키 + 모델 설정

WSL Ubuntu bash
# API 키 등록
cat >> ~/.bashrc << 'EOF'
export DEEPSEEK_API_KEY="여기에_API_키_입력"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
export AIDER_MODEL="deepseek/deepseek-v4-pro"
EOF
source ~/.bashrc

# Claude 행세 방지 모델 설정 다운로드
curl -o ~/.aider.model.settings.yml \
  https://raw.githubusercontent.com/helena751107/helena_phone/main/configs/aider.model.settings.yml

ds 래퍼 설치

WSL Ubuntu bash
mkdir -p ~/bin
cat > ~/bin/ds << 'DSEOF'
#!/bin/bash
REPO="${REPO:-$HOME/work/helena_phone}"
MODEL="${AIDER_MODEL:-deepseek/deepseek-v4-pro}"
cd "$REPO" || { echo "❌ $REPO 없음. git clone 먼저."; exit 1; }
echo "🔧 ds = Aider + DeepSeek"
echo "  model: $MODEL  |  cwd: $(pwd)"
aider --model "$MODEL" \
  --model-settings-file ~/.aider.model.settings.yml \
  --edit-format diff --chat-language Korean \
  --no-auto-commits --dark-mode --pretty "$@"
DSEOF
chmod +x ~/bin/ds

Phone 쪽 aliases

Phone의 ~/.bashrc에 추가하면 편리한 단축 명령어.

Phone — ~/.bashrc
# PC 연결 aliases (PC_IP를 실제 Tailscale IP로 변경)
export PC_IP=100.x.x.x
export PC_USER=사용자명

alias pc="ssh ${PC_USER}@${PC_IP}"
alias pc-work="ssh ${PC_USER}@${PC_IP} -t 'cd ~/work/helena_phone && exec bash -l'"
alias pc-push='git push && ssh ${PC_USER}@${PC_IP} "cd ~/work/helena_phone && git pull --recurse-submodules"'
alias pc-status='ssh ${PC_USER}@${PC_IP} "cd ~/work/helena_phone && git status --short"'
alias pc-ds='ssh ${PC_USER}@${PC_IP} -t "cd ~/work/helena_phone && ds"'

# 사용법:
# pc           → PC에 SSH 접속
# pc-work      → 작업 디렉토리로 바로 이동
# pc-push      → push하고 PC에도 pull
# pc-status    → PC 작업 상태 확인
# pc-ds        → PC에서 Aider 실행

최종 점검 목록

  • Windows: python --version — Python 3.12+
  • Windows: aider --version — Aider 설치 완료
  • Windows: echo %DEEPSEEK_API_KEY% — API 키 설정됨
  • Windows: echo %ANTHROPIC_BASE_URL% — https://api.deepseek.com/anthropic
  • Windows: ds 명령어가 PATH에 있음
  • WSL: wsl -l -v — Ubuntu 실행 중
  • WSL: aider --version — Aider 설치 완료
  • WSL: ls ~/.aider.model.settings.yml — 모델 설정 있음
  • Tailscale: 양쪽 기기 같은 tailnet — tailscale status
  • SSH: Phone → WSL 암호키 로그인 성공
  • Git: WSL에 ~/work/helena_phone 클론 완료
  • 최종: Phone에서 pc-ds → Aider 실행 → 말로 작업 지시
