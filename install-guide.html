🔰 초심자 설치 가이드

구형 안드로이드 폰 하나로 AI 워크스테이션을 세팅하는 전체 과정.
준비물: 폰 + WiFi + 이메일 주소. 비용 0원.

이 가이드는 실제 helena751107의 구축 과정을 초심자용으로 재구성했습니다.

Step 0

📱 구형 안드로이드 폰 준비

Android 10 이상, 저장공간 10GB 이상이면 충분. Galaxy S21 기준으로 작성됐지만 다른 폰도 가능. 삼성폰이면 루팅하지 마세요 (삼성페이·뱅킹앱 망가집니다).

  • WiFi 연결 확인
  • 저장공간 10GB 이상 확보
  • 배터리 50% 이상
Step 1

📦 Termux 설치 (F-Droid 버전!)

⚠️ Play Store 버전은 업데이트가 중단됐습니다. 반드시 F-Droid에서 설치하세요.

폰 브라우저 → f-droid.org → F-Droid APK 다운로드·설치 → F-Droid 앱에서 "Termux" 검색 → 설치

# 설치 후 Termux 앱을 열고 아래 명령어를 한 줄씩 입력하세요
Step 2

🔑 DeepSeek API 키 발급

Claude Code를 무료로 돌리기 위한 엔진입니다. Anthropic 정품 대신 DeepSeek를 씁니다.

  1. 폰 브라우저 → platform.deepseek.com
  2. 회원가입 (이메일 또는 Google 계정)
  3. 왼쪽 메뉴 → "API Keys" → "Create new key"
  4. 키 복사 (sk-... 형식)
# 발급받은 키를 메모해두세요. 나중에 필요합니다. # 형식: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
💡 비용: DeepSeek는 API 호출당 과금이지만, 소량 사용이면 한 달에 만 원도 안 나옵니다. 신규 가입 시 무료 크레딧도 줍니다.
Step 3

🐙 GitHub 계정 + 토큰 발급

코드 저장·웹사이트 호스팅·AI 작업 기록을 위한 필수 계정입니다.

  1. github.com/signup → 계정 생성 (무료)
  2. 로그인 → 우측 상단 프로필 → Settings
  3. 왼쪽 메뉴 맨 아래 → Developer settings → Personal access tokens → Tokens (classic)
  4. "Generate new token (classic)"
  5. Note: "s21-phone" / Expiration: "No expiration"
  6. 권한 선택: repo (전체), workflow
  7. "Generate token" → 토큰 복사 (ghp_... 형식)
⚠️ 중요: 이 토큰은 비밀번호입니다. 절대 다른 사람에게 공유하지 마세요. 복사해서 안전한 곳에 보관하세요.
Step 4

🐧 proot Ubuntu 설치

Termux 안에 Ubuntu 리눅스를 올립니다. 이 위에서 Claude Code가 돌아갑니다.

pkg update -y && pkg install -y proot-distro proot-distro install ubuntu

※ 설치에 3~5분 걸립니다. 커피 한 잔 하세요.

Step 5

⚡ 1줄 설치 실행

아래 명령어에서 GITHUB_USER와 GITHUB_TOKEN을 본인 걸로 바꾸고 실행하세요.

GITHUB_USER="내아이디" GITHUB_TOKEN="ghp_..." DEEPSEEK_API_KEY="sk-..." bash <(curl -sL https://raw.github.com/helena751107/helena_phone/main/g/install.sh)

변수를 안 넣으면 대화형으로 하나씩 물어봅니다. 초심자면 그냥 엔터 치고 대화형으로 진행하세요.

Step 5b (선택)

변수 없이 대화형으로 설치

bash <(curl -sL https://raw.github.com/helena751107/helena_phone/main/g/install.sh)
Step 6

🤖 Telegram 봇 설정 (선택)

AI 작업 완료 알림을 텔레그램으로 받습니다. 없어도 Claude Code는 잘 돌아갑니다.

  1. Telegram 앱 → @BotFather 검색 → /newbot
  2. 봇 이름·유저네임 설정 → 토큰 복사
  3. 새 봇에게 아무 말이나 1회 전송
  4. 브라우저: https://api.telegram.org/bot[토큰]/getUpdates
  5. 응답에서 "chat":{"id":숫자} 확인
echo 'export TG_TOKEN="봇토큰"' >> ~/.bashrc echo 'export TG_CHAT="챗ID"' >> ~/.bashrc source ~/.bashrc
Step 7

🏥 건강 검진 실행

bash ~/work/phone-health.sh

27개 항목을 자동 진단합니다. A등급 이상이면 정상입니다.

Step 8

🚀 Claude Code 첫 실행

proot-distro login ubuntu cd /root/work claude

이제 말로 코딩하세요. "구구단 출력하는 파이썬 코드 만들어줘"라고 말해보세요.

🎉 설치 완료!
